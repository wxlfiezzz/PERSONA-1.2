# Persona 1.3

Node.js 24+, SQLite, браузер. Внешних npm-зависимостей нет.

**Для существующего VPS сначала прочитайте [UPDATE-RU.md](UPDATE-RU.md).** Для его обновления предусмотрен `deploy.sh`. Не запускайте Compose поверх текущего ручного Docker-контейнера `persona`.

## Локальный запуск

`npm start` запускает http://127.0.0.1:3000. На Windows также можно использовать `START.cmd` (порт 3187). Отдельная база задаётся через `DATA_DIR`. Тестовые данные и аккаунты в архив не включены.

## Новое в 1.3

- Исправлено наследование оформления. Общий вид применяется ко всем чатам; персональный вид конкретного чата задаётся явно. Полный сброс очищает все такие переопределения, сброс профиля убирает его оформление и возвращает присутствие «В сети».
- Прокрутка мышью, клавиатурой и пальцем сохранена; полосы прокрутки скрыты. Меню закрываются нажатием снаружи. Кнопка оформления доступна в мобильной шапке.
- Встроены Manrope, Rubik, Lora, Nunito, Montserrat, Oswald, Comfortaa, Raleway. Источник: [Google Fonts](https://github.com/google/fonts); лицензии OFL рядом со шрифтами в public/fonts. Старый выбор шрифтов и узоры убраны из интерфейса.
- Профиль: готовые варианты местоимений, Discord, Telegram, Instagram, ВКонтакте и TikTok. Telegram принимается как @username. Discord показывается как имя для добавления в друзья, поскольку универсальной ссылки на профиль по имени нет. Акцент профиля и лишние кнопки убраны.
- Беседа открывается нажатием на название. Можно задать её аватар/баннер, описание, посмотреть состав. Владелец назначает администраторов. Они создают до 30 ролей с названием, цветом и отдельными правами; одному участнику назначается одна роль. Роль не даёт права управлять другими ролями или администраторами.
- Режим канала запрещает публикацию обычным участникам; писать могут администраторы и роли с правом записи. Вступление — по коду с возможностью его обновления. Старые URL-приглашения совместимы, новые интерфейс показывает как код.
- Из папки архива можно выбирать чаты для переноса. Корень архива — самостоятельное место назначения. Защита паролями и срок разблокировки сохранены.
- Голосовая запись временно убрана. Старые аудиосообщения остаются доступны.
- Чек-ин в личном диалоге: один исходящий запрос за 24 часа на все чаты. Пять минут на ответ после доставки в открытое приложение; фото +1, отказ/тайм-аут −1. Камера включается только по нажатию, кнопки галереи нет. Отключение функции, блокировка и недоступная камера отменяют запрос без штрафа. Недоставленный запрос истекает через сутки. Есть история, счёт и отдельное число успешных ответов. При отключённой вкладке доставка возобновляется после её открытия.
- Приватность: чек-ины, присутствие, публичная статистика, прямые приглашения и новые диалоги. Уже существующие диалоги остаются доступными; для их запрета используется блокировка.
- Persona News показывает векторную иллюстрацию возможностей 1.3; она хранится в public/news-1.3.svg и не требует стороннего сервиса. Для следующего релиза подготовьте новый SVG и привязку к его ID в клиенте.

Фото из чек-ина доступно участникам соответствующего диалога с теми же проверками архива. Это не доказательство свежести снимка: модифицированный клиент или виртуальная камера могут подменить кадр. Проверка всех моделей телефонов и внешний аудит безопасности не проводились.

## Возможности

Личные диалоги, группы, история страницами, поиск, ответы, редактирование, удаление, реакции, закрепление, блокировки, жалобы, файлы до 25 МБ, профили, аватары, темы и локальные черновики.

Возможности 1.1 сохранены:

- Persona News: системный аккаунт, однократная рассылка обновлений всем пользователям.
- Просмотр изображений внутри приложения, скачивание и переключение между фото текущей страницы.
- Кликабельные @username и имена авторов с открытием профиля.
- Компактные серии сообщений одного автора в пределах пяти минут, плавные переходы и reduced motion.
- Новый дизайн, тёмная и светлая темы.
- Прямое добавление до 50 участников за раз владельцем или администратором группы, с учётом блокировок и лимита 500 участников.
- Мобильный интерфейс с safe area, адаптацией под клавиатуру и историей по 100 сообщений. На сенсорных устройствах Enter переносит строку.
- Лёгкий опрос изменений для Quick Tunnel; обновление DOM только изменившихся сообщений.

## Сохранено из 1.2

Статусы присутствия, загрузка и кадрирование аватаров/баннеров, GIF-баннеры, просмотр чужого профиля, двусторонняя блокировка и защита архива сервером. ## Данные и настройки

Данные: `data/persona.sqlite`, вложения: `data/uploads/`. Миграции выполняются автоматически в транзакции и регистрируются в `schema_migrations`. Рассылки из `release.json` учитываются в `release_deliveries`. Пароли и сессии сохраняются.

| Переменная | Назначение |
| --- | --- |
| HOST | 127.0.0.1; в Docker 0.0.0.0 |
| PORT | 3000 |
| DATA_DIR | ./data; в Docker /app/data |
| APP_ORIGIN | Точный внешний HTTPS-адрес без завершающего / |
| COOKIE_SECURE | 1 для внешнего HTTPS |
| REGISTRATION_CODE | Код новых регистраций; пустой означает открытую регистрацию |
| REALTIME_TRANSPORT | poll по умолчанию; sse для совместимого прокси |
| MAX_USER_UPLOAD_BYTES | Квота вложений одного пользователя, по умолчанию 536870912 (512 МБ) |
| NEWS_AUTO_PUBLISH | 0 отключает автопубликацию release.json |

Для новой установки с доменом есть Compose и Caddy. Создайте `.env` по примеру, один раз создайте том `docker volume create persona-data`, затем выполните `docker compose up -d --build`. Том объявлен внешним с точным именем `persona-data`, чтобы не получить пустой том с префиксом проекта. Для текущего VPS используйте только инструкции обновления.

## Тесты

`npm test` использует отдельные временные базы. Проверяются исходные функции, миграции, сохранность данных, новости, приглашения, права доступа и откат. `tests/fixtures/legacy-server.mjs` — исходная версия из предоставленного архива для проверки совместимости; в Docker она не попадает.

## Границы версии

Нет сквозного шифрования, восстановления пароля, 2FA, звонков, push в закрытом браузере и интерфейса обработки жалоб. Сервер работает одним процессом: сигналы обновления хранятся в его памяти. Камера чек-ина требует HTTPS/localhost и разрешения пользователя. После возвращения в скрытую вкладку подгружается новая история.

Удаление участника не является баном: отзовите старую ссылку, если повторный вход нежелателен. Файлы после удаления сообщения остаются на диске. Объём диска и резервные копии обслуживает владелец VPS. Просмотрщик листает изображения текущей страницы истории.

Резервируйте весь остановленный том, включая WAL и вложения. Копирование одного SQLite-файла во время записи не является согласованной копией.


## Архив и безопасность

Пароли папок хранятся в виде scrypt-хешей. Это серверная проверка доступа, не шифрование SQLite/вложений и не защита от администратора VPS или уже скачанного файла. Сброса забытого пароля в интерфейсе нет. Для защищённых чатов черновики и очередь повторной отправки хранятся только в памяти вкладки и очищаются при закрытии архива. После ручного закрытия или истечения срока нужно вводить пароль снова.

Не откатывайтесь на 1.1 или 0.1 при наличии защищённых папок: эти версии не проверяют их пароли. Комплектный rollback-guard блокирует такой откат. Для восстановления нужна версия, знающая архив (1.2+), либо отдельно подготовленная копия данных.

Медиа профиля: аватар до 2 МБ, баннер/фон до 8 МБ, до 100 МБ на аккаунт. Кнопка очистки медиа убрана из редактора; администратор может организовать очистку после резервного копирования. PNG/JPEG/WebP/GIF проверяются по сигнатуре; SVG/HTML не принимаются как оформление. Произвольные CSS и скрипты в настройках не допускаются.

Мобильная версия рассчитана на современные браузеры с HTML dialog, ES modules и VisualViewport/dvh либо доступным резервным размером. Проверена адаптация 320/390/768 px; это не сертификация всех телефонов. Реальные Safari iOS и Chrome Android требуют проверки на устройствах перед массовым выпуском.
